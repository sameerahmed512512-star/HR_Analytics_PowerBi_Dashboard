# HR Analytics Dashboard

## 📊 Project Overview

This is my first Power BI project, focused on analyzing Human Resources data and creating an interactive HR Analytics Dashboard.

The project started with data cleaning and preparation in Microsoft Excel/Power Query, followed by data analysis and visualization in Microsoft Power BI.

The dashboard provides insights into employee demographics, attrition, salary, job roles, education, gender, age, and years at the company.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Clean and prepare HR data for analysis
- Analyze employee attrition
- Identify important HR trends and patterns
- Analyze employee demographics
- Compare attrition across different job roles
- Analyze salary slabs and employee attrition
- Analyze attrition by education and gender
- Analyze employee age groups
- Create an interactive and easy-to-understand HR dashboard

---

## 🧹 Data Cleaning

Before creating the dashboard, the dataset was cleaned and prepared to improve data quality and accuracy.

The data cleaning process included:

- Removing duplicate records
- Handling missing values
- Checking data types
- Formatting columns
- Creating required calculated columns
- Checking inconsistent values
- Preparing the dataset for visualization

## 📈 Dashboard KPIs

The dashboard contains the following key performance indicators:

- Total Employees: **1,470**
